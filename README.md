Download both the .bst and .sty into your LaTeX project, and use `\usepackage{cyfeiriad}` to have it all set up for you. Feel free to modify either file as per the license.
A more thorough guide for the non-user can be found at [https://cyfeiriad.cyruscastle.com/](https://cyfeiriad.cyruscastle.com/), or, contact me at [crc18@aber.ac.uk](mailto:crc18@aber.ac.uk).
